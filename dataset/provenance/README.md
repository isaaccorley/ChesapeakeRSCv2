# Source inventories

| File | Contents |
| --- | --- |
| `county_inventory.csv` | County label raster URLs, filenames, sizes, years, and identifiers used by the downloader and extractors |
| `county_naip_years.csv` | County label vintages and corresponding NAIP program years |
| `v1_splits/` | Original ChesapeakeRSC training, validation, and test patch IDs used for the optional legacy subset |

The inventories describe the Chesapeake Bay Land Use/Land Cover 2024 Edition and its NAIP imagery matches. See the [build instructions](../README.md) for how these inputs are used.
